# Security policy

Kalender Indonesia has no accounts, no user data storage and no secrets in the client. Relevant issues include injection through query parameters, cross-site scripting in rendered pages or embeds, cache poisoning, and supply-chain risks in build dependencies.

Please report vulnerabilities privately through GitHub's "Report a vulnerability" (Security tab) on <https://github.com/rezaprama/kalender>, or contact the maintainer via <https://rezaprama.com>. Include steps to reproduce. You will get an acknowledgement within 7 days.

Data errors (a wrong holiday date) are not security issues. Please open a normal issue with the government source.
