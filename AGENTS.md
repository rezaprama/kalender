# Repository instructions

Read `CLAUDE.md` and `docs/AGENT_HANDOFF.md` before changing this repository.

## Authorship

- Attribute commits to the actual human author. Preserve real human co-authors.
- Do not add AI assistants or vendors as authors, committers, co-authors, sign-offs, or promotional credits in commit messages or pull request descriptions. This includes Claude, Anthropic, Codex, ChatGPT, Gemini, and Copilot.
- Keep the owner's identity and required third-party license notices intact.
- Never rewrite published history or move release tags to change attribution.
- Run `npm run hooks:install` once per clone. CI also checks newly introduced commits with `npm run check:attribution`.

Code and commit messages use English. Communicate with the owner in Bahasa Indonesia.
